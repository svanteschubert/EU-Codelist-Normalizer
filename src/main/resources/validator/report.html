Codes that differ

“Accepted, not published”: the validator lets an invoice use a code the code list does not contain. “Published, not accepted”: an invoice using a published code is rejected. The complete lists are in rules.csv.

Index sheet: stated against actual changes

Each workbook's Index sheet states, per tab, whether the list changed (“Changes”) and how (“Remark on updates”). Every revision is compared with the release before it: first with its own code list sheet, then with its Genericode file, which is also compared with the sheet. Where releases without Genericode lie between two that have it, the Genericode file is compared across them. Full details are in index-claims.csv.
