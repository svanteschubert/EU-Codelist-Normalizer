Disagreements per effective date

Each code-list rule of the validator (BR-CL-01 to BR-CL-26) checks an invoice field against a list of codes written into the rule. Every such list is compared, code by code, with the code list the Commission published for the same date, once as Genericode and once as spreadsheet.

How to read a cell, for example 7 of 22 rules · 11 codes differ:

  • 22 rules of this syntax could be compared with this component. The Genericode column can count one fewer: BR-CL-06 checks the Time sheet, which was never published as Genericode.
  • 7 of them accept a different set of codes than the component lists.
  • 11 codes differ across those 7 rules, counted once per rule. A code both BR-CL-03 and BR-CL-04 get wrong counts twice, because both checks fail an invoice.
  • all 22 agree: every rule accepts exactly the listed codes. not published: that release has no such component; before 2021 the code lists were published as spreadsheet only.
