EN 16931 code lists

Unofficial showcase. The authoritative code lists and validation artefacts are those the European Commission publishes in its Registry of supporting artefacts to implement EN16931; where this site differs, the Registry prevails.

The code lists an EN 16931 invoice may use, as the European Commission publishes them, and as the CEN validation artefacts implement them.

Code lists: declared and implemented Every effective date: whether the spreadsheet, the Genericode files and the Index sheet's change notes agree, and whether the validator implements the declared codes. Each finding links to where it is written. Release by release The code-history branch: one commit per effective date of the code lists, oldest first, each holding the last revision of its release, so that GitHub shows what changed from one release to the next. Extracted and normalized code lists Every release, by version, effective date and revision: extracted/ holds the Genericode files as the archives hold them and every workbook sheet as CSV, normalized/ the same sorted by code, each directory with the source.json naming its original. Original files The workbooks, Genericode archives and validation artefacts exactly as downloaded from the Registry, kept by EU-Codelist-Downloader.
